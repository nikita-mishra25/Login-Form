# 🔐 Login Form Project

This is a simple **Login Form** project built using **HTML, CSS, and JavaScript**.  
It demonstrates form handling and basic input validation.

---

## 🚀 Features
- Username and password input fields
- Login button
- Basic form validation
- Error message display
- Clean and responsive UI
- Beginner-friendly JavaScript logic

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
